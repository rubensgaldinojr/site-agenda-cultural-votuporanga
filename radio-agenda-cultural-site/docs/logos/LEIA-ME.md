Arquivos prontos (PNG com fundo transparente). **Nada daqui vai no zip do tema**: são para você subir no WordPress.

| Arquivo | O que é | Onde usar |
|---|---|---|
| `logo-horizontal-claro.png` | Logo principal (símbolo + "agenda cultural"), cores originais | **Logo do site** (Aparência → Personalizar → Identidade do site → Logo) |
| `logo-horizontal-escuro.png` | Mesma logo para fundo escuro (letras e arco em creme `#F3ECE3`; laranja mantido; recortes transparentes) | **Logo para fundo escuro** (campo do tema, no mesmo lugar) |

| `favicon-512-transparente.png` | Símbolo sem fundo, 512×512 | Alternativa (o arco azul some em abas escuras) |
| `favicon.ico` | Mesmo ícone em 16, 32, 48 e 64 px | Só se algum serviço pedir `.ico` |

## Como subir no WordPress
1. **Aparência → Personalizar → Identidade do site.**
2. **Logo:** `logo-horizontal-claro.png`.
3. **Logo para fundo escuro:** `logo-horizontal-escuro.png` (campo criado pelo tema; sem ele a logo principal é clareada por um filtro).
4. **Ícone do site:** `favicon-512.png` (o WordPress pede um quadrado de pelo menos 512×512 px).
5. Publicar. O favicon pode demorar para aparecer na aba (cache do navegador): teste em uma aba anônima.

## Como foram feitos
- Cores da marca: azul `#171F25`, laranja `#EC934B`.
- Versão escura: azul vira creme (cor do texto do modo escuro do site), o branco interno vira transparente e o laranja não muda.
- O símbolo original (512×512) vinha **cortado reto nas 4 bordas** (o círculo era um pouco maior que a tela); o símbolo daqui foi recortado num círculo perfeito.
- Para refazer a partir do original, peça ao Claude.
